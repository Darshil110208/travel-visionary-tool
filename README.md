# Trip Weaver

Build a premium modern tourism planning web application called "TravelOpt".

The main screen should allow users to enter:

destination

travel dates or number of days

budget

number of travellers

travel style

nature preference

history preference

adventure preference

food preference

beach preference

nightlife preference

maximum daily travel time

sustainability preference

Create a visually impressive dashboard.

After clicking "Optimize My Trip", show:

total estimated cost

budget remaining

preference satisfaction score

sustainability score

total travel distance

attractions selected

day-by-day itinerary

map

hotels

restaurants

explanation of why each attraction was selected

"Re-optimize" button

Include loading animations and a professional tourism visual design.

Do not build a chatbot-centric UI.
